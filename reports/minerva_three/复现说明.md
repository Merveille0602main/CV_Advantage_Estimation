## 从采集重跑

使用具有 LIBERO 场景、固定版本 MINERVA 代码和权重的环境。沿用上节的仓库环境变量，另选一个新输出目录。数据获取时固定上述版本并保留 meta 与所需的低维 Parquet。图像由模拟器实时生成。准备示范库的 Python 环境需要 NumPy、PyArrow 和 pandas，可以与仿真环境独立。

从本报告目录运行下面的 Python 片段，可按本次清单下载对应的 93 个低维文件和元数据。示范派生数组保留原始轨迹与帧号，原数据集标注的许可证为 Apache-2.0。

```python
import json
from pathlib import Path
from huggingface_hub import snapshot_download

manifest = json.loads(Path("run01/demo_sources.json").read_text())
snapshot_download(
    repo_id=manifest["dataset"],
    repo_type="dataset",
    revision=manifest["revision"],
    allow_patterns=["meta/**", *manifest["sha256"].keys()],
    local_dir="/mnt/d/CV/data/raw/lerobot_libero",
)
```

```bash
export STUDY_ROOT="$(mktemp -d)/run01"
export MINERVA_WEIGHTS=/mnt/d/CV/minerva_smoke/inputs/t05_0.54M
export MINERVA_PYTHON=/home/figo/minerva_smoke/venv/bin/python
export LIBERO_CONFIG_PATH=/home/figo/minerva_smoke/libero-config
python "$repo/reports/minerva_three/scripts/prepare.py" /mnt/d/CV/data/raw/lerobot_libero --weights "$MINERVA_WEIGHTS"
bash "$repo/reports/minerva_three/scripts/run.sh" complete
```

若已下载发布数据，在新的采集目录直接放入顶层的 `demo_sources.json`、`protocol.json`，以及每任务的 `demo.json` 和 `demo_library.npz`，即可从最后一条命令开始。三个任务的目录分别为 13、19、25。奶酪任务复用上一轮的 100 条轨迹和 6 个基线模型。新任务各自按 35／5／10 个初始状态划分，每个初始状态执行两个原始策略种子。

## 输出与指标

- 示范库保存逐行的源轨迹、帧号、八维状态和七维动作；`demo_sources.json` 保存原始文件哈希。80% 示范轨迹作为训练分支动作供体，其余作为测试分支供体。近邻尺度只从训练供体拟合。同一个机器人状态对应的物体位置和策略历史可能不同，因此每个移植动作都在目标场景实测。
- `anchors/` 保存首步候选、近邻出处、恢复误差和快照哈希。发布包包括全部 90 个测试快照。训练快照可从轨迹、种子和代码重建。每个快照验证原后缀的全部动作、低维状态、奖励和长度。分支每次恢复还核验积分状态与双相机图像。设置 `MINERVA_RENDER_PREFIX=1` 可启用前缀每一帧的完整渲染。
- `augmentation/` 保存普通续跑和更换首步续跑两个训练组。各使用相同的 12 个训练初始状态、4 个各为 1,500 控制步的预算分片。前缀恢复是两组共有的准备开销。末尾因预算截断的片段计入成本，只有完整后缀参与蒙特卡洛训练。训练采样覆盖完整后缀的每个 transition。V 在三个 Q 对照组间共享。
- `train_diagnostic.csv` 从两个训练组取同快照、同种子且两边都已完整结束的续跑，比较原始 Q 的预测差与一次配对实测差。`19/drawer_model_probe.json` 对 36 个训练快照分别更改模型输入中的平移、夹爪或两者，检查开抽屉 Q 的数值敏感性。单独更改输入的两项仅用于解释模型输出。
- `evaluation/` 分开保存每个测试快照的 8 个配对完整续跑种子和另外 2 个短续跑种子。每个完整续跑记录成功与步数，短续跑含观测状态、动作和奖励。多步估计可见真实后续步骤；Q−V 只读当前状态和候选动作。
- `predictions.csv` 是逐候选、逐训练种子的预测；`pairs.csv` 是全部动作对的真实差、置信区间和预测差。`metrics.json` 与总表 `summary.json` 先按快照、再按初始状态等权。主指标比较四种替代动作与原动作的折扣回报差，先对每个训练种子计算 RMSE，再取三种子平均。
- 排序覆盖率的分母包括全部五种候选形成的十对比较。判据为配对重采样区间整体越过 ±0.005，且至少 6/8 次同向。组间 RMSE 差的区间按测试初始状态配对重采样，条件为当前的参考续跑。每任务只有十个独立测试初始状态。
