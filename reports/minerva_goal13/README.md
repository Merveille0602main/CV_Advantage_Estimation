### 复核结果

从本分支仓库根目录运行下面的命令。机器需有 Python 3.10 或更高版本、NumPy 和可在 CPU 推理的 PyTorch。实验训练环境使用 Python 3.12、NumPy 1.26.4、PyTorch 2.7.1。

```bash
python reports/minerva_goal13/verify_results.py
```

程序在临时目录读取 6 个模型、240 次参考续跑和 60 条独立评分分支，重新计算两项实验的数值，并核对逐对和逐动作记录。评分分支包含从冻结测试状态出发生成的实际动作、后续状态和奖励。复核现有分数可完全在 CPU 上进行。

随附全部 100 条低维训练／验证／测试轨迹和本次评价实际使用的 10 个测试快照。原训练共保存 70 个快照，完整哈希清单见 [snapshot_hashes.json](20261119_run01/snapshot_hashes.json)。重做物理仿真需要 MINERVA 权重和 LIBERO 环境；原始采集、训练、分支脚本保留了实验机的 WSL 路径和设置。[实验脚本](scripts)
