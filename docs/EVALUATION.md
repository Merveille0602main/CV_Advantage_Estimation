# 评价协议：模型分数与独立标签分开

## 人工环境

人工数据不是任意拼接的状态对，而是由已知随机转移、固定参考策略和有限时限生成的完整轨迹。
已知环境可以通过反向动态规划精确计算该参考策略的 V 和 Q。
训练只读取训练轨迹观测、动作与实际奖励；oracle 不参与梯度、目标构造或 checkpoint 选择。

主指标：同状态候选动作的成对排序准确率，先在 anchor 内平均，再对 anchor 平均。
预测平手记半分。精确动作价值差不超过预设最小差异的动作对标记不可辨，保留其覆盖率。
没有可辨动作对时返回无结果，而不填零或一。
补充指标：对精确 Advantage 的数值 RMSE，以及已学习 Q、V 各自对精确值的 RMSE。

MC-Q 减共享 V 与 TD/N-step 同属被评价方法，不能把 MC-Q 的结果拿来给自己或其他方法打分。
TD/N-step 有未来观测权限；Q 减 V 只用当前状态与候选动作。报告中显式列出这种差别。

## 真实数据

优先保存同状态完整快照。强制执行一个候选动作，随后遵循同一个固定参考策略，重复独立续跑。
标签使用独立续跑的平均回报及其不确定性；评分分支与标签分支不得复用。
同状态动作排序只需要比较候选动作的参考 Q，公共 V 会抵消。
如果不能恢复状态、无法执行匹配参考策略，则不能宣称已得到真实反事实 Advantage 标签。

离线文件自带的 return 是一次随机回报，不是真实状态价值。
已学习 Q 与某个评分一致，只说明模型间一致，不能单独证明评分准确。
当前 MC-Q 适用于单一固定参考策略的数据；混合策略、历史不充分和分布外动作需要另行分析。

## 当前实验限制

人工实验默认三个数据/训练种子，每种子最多四十个独立测试轨迹 anchor，每个状态两个候选动作。
每个 TD 候选平均十六次评分分支，再比较排序；不是单次评分性能。
目前报告初步均值和逐种子结果，尚未提供家族 bootstrap 置信区间，不据此宣称统计显著。
